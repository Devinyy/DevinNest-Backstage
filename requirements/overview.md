# 功能基线

状态：用户于 2026-11-06 确认“先以当前代码为基线”。本目录据当前源码整理功能、字段与回归依据，保留未完成功能和待确认项；这不等于对全部现有行为逐项完成业务验收。业务目标变更仍以用户明确要求为准。

## 产品与范围

README 将本项目定义为 Devin's Nest 个人主页的内容管理后台。当前有登录、仪表盘、博客、日常碎片四个功能入口。分类和标签管理嵌在仪表盘中，没有单独页面。

| 模块 | 已有能力 | 详细入口 |
| --- | --- | --- |
| 登录与布局 | 用户名密码登录、RSA 加密、本地状态持久化、受保护路由、折叠菜单、退出 | [认证](modules/auth.md) |
| 仪表盘与分类标签 | 统计、最新动态、词云、分类 / 标签增删改 | [仪表盘](modules/dashboard.md) |
| 博客 | 分页列表、Markdown 编辑、新建 / 编辑 / 删除、封面和正文图片上传 | [博客](modules/blogs.md) |
| 日常碎片 | 卡片列表、四类内容块、新建 / 编辑 / 删除、标签与拍摄元数据 | [碎片](modules/snippets.md) |

## 当前不应宣称已完成的能力

- 博客与碎片草稿：按钮仅提示“暂未开放”。博客提交固定 `status: 'published'`。用户已确认目前不需要草稿，不列为当前待开发项（SC-001）。
- 注册、找回密码、多用户权限和角色管理：没有对应路由及页面。
- 通知、个人中心、设置：有界面入口，未发现对应业务处理。
- AI 助手、项目管理：仅有 API 文件，未发现页面调用。
- 全端响应式：部分页面有响应式网格；主布局和首页仍有固定尺寸 / 栅格，不代表已完成移动端验收。

## 需求使用方式

开发任务先确认目标模块和用户要求，再读模块说明。模块中的行为与字段均标记为代码现状；如果用户要求与现状不同，更新需求并记录差异，不因“现有代码如此”否定业务要求。后端数据约束、真实用户权限、分类删除后的关联规则等不能由前端代码推出。

## 已确认范围补充

目标规则统一见 [confirmed-rules.md](confirmed-rules.md)。设备以电脑为主、手机能完成主要操作（UI-001）；不将未验证的响应式实现视为已验收。草稿当前不需要（SC-001），其他规则的实现差距见偏差记录。
