# 仪表盘、分类与标签行为基线

证据：[Dashboard](../../src/pages/Dashboard/index.tsx)、[统计 API](../../src/api/dashboard.ts)、[分类标签 API](../../src/api/taxonomy.ts)。

## 数据与导航

- 页面加载通过 Promise.all 并发读取统计、分类、标签；统一控制加载状态。任一失败进入整体异常处理，不是各区块独立降级。
- 两张主统计卡展示博客 / 碎片总数及本月新增；本月新增缺失按 0 显示，点击进入对应列表。
- 最新动态来自 `latestActivity`，显示标题、类型、封面、分类 / 标签、时间。博客动态进入对应编辑页；碎片动态进入碎片列表。
- 标签词云使用标签名和 `count || 1`，没有标签时显示空状态。统计 API 另定义分类、标签总数字段，不代表每个字段均有单独卡片。

## 分类管理

- 在首页区域新增 / 编辑，弹窗使用 name、icon、color；name 必填且去空格后非空才允许提交。
- 图标提供 Ant Design 名称选项，也允许输入 CSS Class；颜色预设值是 Tailwind 样式字符串。
- 删除入口在悬浮操作区，直接请求 deleteCategory，当前没有确认弹窗。
- 新增 / 编辑 / 删除成功后静默重新拉取统计、分类和标签。

## 标签管理

- 新增 / 编辑字段为 name、color；name 必填，color 输入名称（如 blue）。
- 部分标签名存在预设颜色映射；展示时还会按名称计算备用颜色，不等同于所有颜色均写入后端。
- 删除直接调用 deleteTag，当前没有确认弹窗；成功后刷新首页数据。

## 已确认的目标行为（2026-11-06）

- [TX-001](../confirmed-rules.md#tx-001分类和标签的删除保护)：有引用时禁止直接删除，先迁移或解除关联；无引用时经二次确认删除，保留内容。当前前端待补确认流程，本地后端未见业务引用检查。
- [TX-002](../confirmed-rules.md#tx-002同库禁止重名)：各自库内禁止重名，博客与碎片标签允许同名；前端未校验，本地后端原名等值查询及全局标签表尚不满足完整规则。
- 碎片标签归属见 [SN-002](../confirmed-rules.md#sn-002新标签进入碎片公共标签库)，不能把名称相同当成跨库共享依据。

## 后端代码口径与剩余验证

本地后端已核对：分类计数只计博客；标签计数也只计博客，不计碎片；总量不按博客发布状态过滤；本月按服务器月初下界统计；最新动态按创建时间合并取 5 条。证据和边界见 [后端核对记录](../../docs/backend-evidence.md)。数据库实际引用删除效果、线上部署版本、迁移 / 解绑方式尚未验证，不将源码核对等同接口验收。
