# 需求地图

本目录是产品目标与现状基线的入口。用户于 2026-11-06 确认先以当前代码为基线，保留未完成功能与待确认项；新增业务规则仍需明确需求。

| 资料 | 用途 | 边界 |
| --- | --- | --- |
| [README 功能说明](../README.md#-功能特性) | 理解后台已有功能概览 | 概览不等于完整验收标准，Roadmap 不等于已实现 |
| [功能基线](overview.md) / [模块地图](modules/MAP.md) | 按源码整理的已有行为、字段和未实现边界 | 未经逐项业务确认，不作为新增需求授权 |
| [已确认业务规则](confirmed-rules.md) | 用户确认的目标行为及实现状态 | 碎片校验及标签归属、分类标签删除与重名、离页提醒、草稿范围、设备目标 |
| 当前用户请求及已确认的补充 | 确定本次目标、约束和验收范围 | 以明确授权为准，不擅自扩大 |
| [API_DOCS.md](../API_DOCS.md) | 联调时查对应模块的字段和接口 | 是接口资料，不是独立产品 PRD；需与实现 / 后端核对 |
| [实现地图](../harness/impl.md) | 查询当前支持的页面和模块 | 只反映现状 |

当前仓库没有独立、经确认的完整 PRD。未来新增需求文档时在此登记来源、状态与模块入口；模块行为已整理在 modules/；后续按实际新增内容扩展。需求与实现不符写入 [偏差记录](../harness/deviations.md)。
