# 现有颜色、文字与交互边界

本页整理实际 UI，提供后续修改时的核对依据；不代替设计稿或可访问性验收。

## 颜色与文案

- 全局暗色，白 / 灰层级文字；主要提交动作局部使用蓝色，删除使用 danger / 红色，统计与分类允许彩色强调。
- 登录页标题 DevinNest、英文输入占位和 Sign In；后台主体使用中文。当前不存在完整国际化层。
- 用户名来自本地 user，缺失时显示 Devin；头像目前使用 UserOutlined，没有绑定 user.avatar。
- 缺图、无内容、列表为空均有各页占位；具体文案在模块源码，不引入重复文案字典。

## 布局与响应式现状

- 碎片列表：grid-cols-1 / md:grid-cols-2 / lg:grid-cols-3。
- 碎片编辑器：大屏区分元信息与内容块；博客编辑器的布局以页面代码为准。
- 主侧栏通过按钮手动折叠，没有配置 Sider breakpoint 自动折叠。首页主要使用固定 Col span=12、16 / 8。
- README 已收敛为“部分页面使用响应式网格”；完整适配仍需实测。

## 交互注意

- 博客 / 碎片删除有 Popconfirm，首页分类 / 标签删除直接执行，二者不能混写成统一确认流程。
- 分类 / 标签编辑删除主要通过 hover 展示；后续 UI 修改需检查触屏与键盘是否可达。
- 列表有 Spin 与空态；错误多由 message 提示。失败后空列表不一定区分“加载失败”与“确实无数据”。
- 编辑页有返回按钮和 sticky 提交栏；未实现未保存离页提醒。用户已确认 [ED-001](../requirements/confirmed-rules.md#ed-001仅有未保存改动时提醒离开)，仅脏状态时提醒。
- 全局菜单 selectedKeys 用完整 pathname，编辑页的列表菜单选中状态需实际检查。
