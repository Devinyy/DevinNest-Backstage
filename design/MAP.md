# 设计地图

用户于 2026-11-06 确认先以当前代码为基线。UI 任务按影响读取现有样式与交互，不把示例内容当成视觉规范；未提供的设计意图不推测补写。

| 资料 | 用途 | 读取条件 |
| --- | --- | --- |
| [样式数值](tokens.md) | 当前颜色、圆角、动效与布局数值 | 主题 / 样式任务先定位对应值 |
| [交互边界](interaction.md) | 现有文案、响应式及操作差异 | UI 交互与验收 |
| [App.tsx](../src/App.tsx) | Ant Design 暗色主题、组件 token | 主题或组件样式变更 |
| [index.css](../src/index.css) | 全局样式与 Tailwind 入口 | 全局样式、布局或响应式变更 |
| [MainLayout.tsx](../src/layouts/MainLayout.tsx) | 后台布局和导航 | 导航、侧栏及整体框架变更 |
| 目标页面 `src/pages/` | 局部样式和现有交互 | 仅受影响页面 |
| [Markdown 示例](../src/web-design-pattern.md) | 编辑器内容示例 | Markdown 内容 / 渲染任务 |

目前未提供独立 Figma 或完整视觉验收稿；tokens.md 是代码提取清单，非用户确认的设计系统。现有样式是实现事实；新增视觉要求以用户提供的设计为准，不凭空建立数值规范。确认的新设计资料在本 MAP 登记来源和适用范围。
